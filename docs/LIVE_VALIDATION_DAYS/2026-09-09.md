## F4 — local Redis re-secured [closed]

  and a fresh `requirepass`; `redis-server` was restarted.
- Created `/etc/aitbc/redis.env` (640, `root:aitbc`) with `REDISCLI_AUTH` so
  `aitbc-cache-monitor` authenticates.
- Updated all local `redis://` consumer URLs under `/etc/aitbc`
  (`REDIS_URL`, `GOSSIP_BROADCAST_URL`, `SYNC_REDIS_URL`, `POOLHUB_REDIS_URL`)
  to `redis://:<pass>@127.0.0.1:6379`.
- Unauthenticated local Redis `PING` now returns `NOAUTH` everywhere.
