# Archived Releases

This directory holds legacy AITBC releases from the v0.0.x–v0.4.x series.

## Available Archive Releases

See the release directories in this folder or the main [release index](../README.md) for notes on the current v0.5.x+ releases.

## Historical Context

- **v0.0.x – v0.3.x**: Early prototypes and proof-of-concept work.
- **v0.4.x**: Pre-marketplace foundation releases focused on blockchain primitives, wallet basics, and agent identity experiments.

Releases from **v0.5.0** onward are actively maintained and documented in the parent `docs/releases/` directory.
