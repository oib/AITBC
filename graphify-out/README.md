# graphify-out/ — Knowledge Graph Artifacts

This directory contains codebase analysis and knowledge graph outputs generated by the Graphify tool.

## Contents

| File | Tracked? | Purpose |
|------|----------|---------|
| `graph.json` | ✓ Yes | Complete knowledge graph (committed; used for analysis) |
| `GRAPH_REPORT.md` | ✓ Yes | Human-readable report (committed; useful for review) |
| `.graphify_labels.json` | ✓ Yes | Label metadata (committed; part of graph annotations) |
| `manifest.json` | ✓ Yes | Manifest of graph content |
| `cache/` | ✗ Ignored | Local extraction cache (regenerated on each run) |

## What Gets Committed

The graph artifacts (`graph.json`, `GRAPH_REPORT.md`, `.graphify_labels.json`, `manifest.json`) are committed to preserve the state of codebase analysis for:

- Code review and architecture discussions
- Historical comparison of codebase evolution
- Onboarding and documentation reference

## What Gets Ignored

The `cache/` directory contains intermediate files and hash-named JSON files used for AST processing. These are:

- Regenerated on each `graphify` run
- Specific to local tool execution
- Not needed in version control (noise in history)

To regenerate the cache after a fresh clone:

```bash
graphify extract [options]
```

This will rebuild `cache/` and regenerate the output artifacts.

## Keeping the Graph Fresh

Agents are steered by this graph first (ADR-A-0003, "graph before grep"), so a
stale graph misleads them. Regenerate and commit the artifacts after significant
code changes and **before every release**:

```bash
graphify update .            # re-extract (no LLM/API cost) → graph.json + GRAPH_REPORT.md
git add graphify-out/graph.json graphify-out/GRAPH_REPORT.md \
        graphify-out/manifest.json graphify-out/.graphify_labels.json
```

`GRAPH_REPORT.md` records the source commit (`Built from commit: <sha>`).
`scripts/pre-release-check.sh` §6 parses it and **warns** when the graph is more
than `GRAPH_STALE_MAX_COMMITS` (default 50) commits behind HEAD — a guard added
in ABS-148 after the graph once drifted 229 commits stale.
